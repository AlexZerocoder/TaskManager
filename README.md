# Менеджер задач


Создан класс `Task`, который позволяет управлять задачами (делами). 

В менеджере задач доступны следующие атрибуты задачи: 

* описание задачи, 
* срок выполнения, 
* статус (выполнено/не выполнено). 


В менеджере задач реализована функция для добавления задач, 
отметки выполненных задач и вывода списка задач с их статусами.

Менеджер доступен через графический интерфейс.
